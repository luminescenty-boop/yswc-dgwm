# 第四阶段验收报告：Godot 4 新版工程

日期：2026-10-30

## 已完成

- 建立 Godot 4 工程，主场景可正常加载。
- 参考画布设为 iPhone 12 横屏逻辑尺寸 `844×390`。
- 移动设备方向设为 `Sensor Landscape`，仅允许横屏左右旋转。
- iOS 导出目标限制为 iPhone、ARM64、最低 iOS 15.0。
- 游戏世界与 UI 分为 `WorldLayer` 和 `UILayer`。
- UI 使用容器、锚点和设备安全区域，不依赖固定屏幕坐标。
- 建立统一输入、音频、三槽存档及场景切换服务。
- 建立高清资源优先、原始资源回退的资源目录。
- 建立资源同步工具，已验证可识别 270 个原始 PNG/MIDI 和 5 个高清试稿。

## 自动化验收

在 Godot 4.6.3 中执行并通过：

- 工程导入与所有 GDScript 编译。
- 主场景无窗口启动，确认参考画布为 `844×390`。
- iPhone 12、iPhone 14 Pro、iPhone 16 Pro Max 三组横屏安全区域换算测试。
- 资源同步测试，共处理 275 个资源。
- iOS 导出预设被 Godot 正确识别。

云端运行机是 Linux，不能运行 Xcode 或 iOS Simulator；实际 `.ipa` 导出还缺少 Godot iOS 导出模板、macOS/Xcode 和 Apple 签名。这属于发布环境要求，不影响当前 Godot 工程及布局代码的验收。首次真机阶段仍应在 macOS 上分别运行 iPhone 12、带灵动岛机型和当前最大尺寸机型。

## 第五阶段入口

下一阶段可以在此骨架上建立主菜单、剧情地图和战斗场景，并逐步把反编译确认的旧版规则接入服务层。资源代码应通过 `ResourceCatalog` 的资源 ID 加载图片，以便后续替换高清资源时无需改游戏逻辑。
